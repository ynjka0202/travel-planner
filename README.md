# Travel Planner

Программчлалын дадлагын (F.CSM360) хүрээнд хийсэн веб систем.

Хэрэглэгч аяллаа төлөвлөж, авч явах зүйлсийн жагсаалт гаргадаг. Аялсны дараа зураг, тэмдэглэлээ хадгалж, өмнөх аяллуудаа timeline болон он, сараар харах боломжтой.

Гүйцэтгэсэн: У.Янжинлхам (B242270131)

## Ашигласан технологи

- HTML, CSS, JavaScript
- Supabase (Auth, PostgreSQL, Storage)
- Vercel

## Боломжууд

- Бүртгүүлэх, нэвтрэх
- Аялал нэмэх (газар, огноо, төсөв, дотоод / гадаад)
- Checklist (авч явах зүйлс)
- Аяллыг дууссан гэж тэмдэглэх
- Зураг, тэмдэглэл нэмэх
- Аяллуудыг жагсаалт болон timeline хэлбэрээр харах
- Дотоод / гадаад аяллаар шүүх
- Сар, жилээр аяллын түүх

## Ажиллуулах

1. Supabase дээр шинэ төсөл үүсгээд SQL Editor дээр `supabase/schema.sql` файлыг ажиллуулна.
2. `js/config.js` файлд Supabase-ийн Project URL болон publishable key-г бичнэ.
3. `index.html`-г Live Server-ээр нээнэ.

Хэрэглэгч бүр зөвхөн өөрийн өгөгдлийг харахаар Supabase дээр RLS дүрэм тохируулсан.

## Бүтэц

